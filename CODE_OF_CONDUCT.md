# Code of Conduct

## Our pledge
We want Erebus to be a welcoming, harassment-free project for everyone,
regardless of experience, background, or identity.

## Standards
Be respectful and constructive. Not acceptable: harassment, personal attacks,
or sharing others' private information. Assume good faith; disagree technically,
not personally.

## Responsible use
Erebus is a security **research and testing** framework for authorized use only —
your own lab or systems you have **written permission** to test. Contributions
must not add features whose primary purpose is to attack systems without
authorization, to target private individuals, or to self-propagate. Security
issues *in Erebus itself* follow the coordinated-disclosure process in
[`SECURITY.md`](SECURITY.md).

## Enforcement
Report concerns to the maintainers via a private channel or a security advisory.
Maintainers may remove contributions or contributors that violate this code.
